# API Reference

This page is a compact map of the current PulseLib public API. Classes marked internal in source are omitted unless they explain a public workflow.

## Animatables and controllers

* [`PAnimatable<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/PAnimatable.java) defines animatable objects, including animated items.
* [`PAnimationManager<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationManager.java) owns regular and graph controller factories, live controllers, and the bound model.
* [`PAnimationController<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationController.java) plays a `PRawAnimation` or `PAnimationGraph`, exposes graph parameters, controls timing, and owns persistent Molang state.
* [`InstanceAnimationManager<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/instance/InstanceAnimationManager.java), [`SingletonAnimationManager<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/singleton/SingletonAnimationManager.java), and [`AnimManagerKey`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/AnimManagerKey.java) provide per-instance and keyed state.
* [`ControllerState`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/ControllerState.java) is `PLAY`, `PAUSE`, or `STOP`.

## Animation data and graphs

* [`PRawAnimation`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PRawAnimation.java) is a builder for staged playback sequences; [`PAnimationType`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationType.java) selects once, hold, or cycle behavior.
* [`PAnimationGraph`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraph.java), [`PAnimationState`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationState.java), [`PAnimationTransition`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTransition.java), [`PCondition`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PCondition.java), and [`PAnimationGraphRuntime`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraphRuntime.java) implement graph states, blend spaces, overlays, transitions, and runtime state.
* [`PAnimationParameters`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationParameters.java) stores graph numeric/boolean inputs and one-use triggers. [`PInterruptionPolicy`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PInterruptionPolicy.java) is used by graph transitions; [`PTransitionInterruptionPolicy`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PTransitionInterruptionPolicy.java) is used by player-animation activation crossfades.
* [`PAnimation`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimation.java), [`PBoneAnimation`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PBoneAnimation.java), [`PAnimationTrack<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTrack.java), and [`PKeyframe<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PKeyframe.java) represent parsed animation data.
* [`PAnimationChannelType<T>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannelType.java) is the generic channel contract. [`PAnimationChannel`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannel.java) supplies vector and quaternion implementations; PulseLib's internal type registry contains position, rotation, and scale channels.
* [`PInterpolation`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolation.java) and [`PInterpolationType`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolationType.java) control keyframe interpolation. [`PBlendMode`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PBlendMode.java) and [`PPoseBlendMode`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PPoseBlendMode.java) control pose blending.
* [`PPose`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PPose.java), [`PModelPose`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PModelPose.java), and [`PAnimationPoseResolver`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationPoseResolver.java) evaluate local and model-space poses.
* [`PRootMotionRuntime`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionRuntime.java) and [`PRootMotionDelta`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionDelta.java) extract incremental root motion from an animation.
* [`PAnimationEvent`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationEvent.java) and [`PAnimationEventDispatcher`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationEventDispatcher.java) provide animation sound and particle events.

## Models and loaders

* [`PModelData`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/modelData/PModelData.java) and its [`DefaultBlockModelData`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/modelData/DefaultBlockModelData.java), [`DefaultItemModelData`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/modelData/DefaultItemModelData.java), [`DefaultEntityModelData`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/modelData/DefaultEntityModelData.java), and [`DefaultEntityLayerModelData`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/modelData/DefaultEntityLayerModelData.java) builders identify models and textures.
* [`PModel`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/PModel.java), [`PBone`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/PBone.java), and [`PMesh`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/PMesh.java) are raw data. [`PBakedModel`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedModel.java), [`PBakedBone`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedBone.java), and [`PBakedMesh`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedMesh.java) are the baked runtime representation.
* [`PMeshRenderContext`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderContext.java) and [`PMeshRenderResolver`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderResolver.java) customize render type, colour, lighting, overlay, deformation, texture, emissive state, and alpha mode for each baked mesh. [`PMeshRenderMaterial`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderMaterial.java) resolves those material overrides.
* [`PModelCache`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/PModelCache.java) manages loaders, resource reloads, baking, and cache cleanup. [`PModelLoader`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/PModelLoader.java) is the extension point.
* glTF classes are in [`data.gltf`](https://github.com/ArcAnc/PulseLib/tree/master/src/main/java/com/arcanc/pulselib/data/gltf): [`PGltfModelLoader`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelLoader.java), [`PGltfModelParser`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelParser.java), and [`PGltfAnimationEventSidecarParser`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/gltf/PGltfAnimationEventSidecarParser.java).
* Gecko and Molang classes are in [`data.gecko`](https://github.com/ArcAnc/PulseLib/tree/master/src/main/java/com/arcanc/pulselib/data/gecko): [`PGeckoModelLoader`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelLoader.java), [`PGeckoModelParser`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelParser.java), [`PGeckoAnimationEventParser`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoAnimationEventParser.java), and [`MolangParser`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/data/gecko/MolangParser.java).

## Rendering, textures, and attachments

* [`PRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/PRenderer.java), [`PBlockRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/PBlockRenderer.java), [`PItemRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/PItemRenderer.java), [`PEntityRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderer.java), and [`PEntityRenderLayer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderLayer.java) are renderer entry points.
* [`PRenderTypes`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/PRenderTypes.java) provides compatible triangle render types; [`PRenderQueue`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/renderer/PRenderQueue.java) batches their submissions.
* [`PTextureCache`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/PTextureCache.java), [`RuntimeLoader`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/textures/atlas/RuntimeLoader.java), and [`PLibSpriteMetadata`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/textures/atlas/PLibSpriteMetadata.java) manage the runtime texture atlas and its emissive/alpha metadata. [`PAlphaMode`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/textures/PAlphaMode.java) and [`PTextureAlphaClassifier`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/textures/PTextureAlphaClassifier.java) select opaque, cutout, or translucent rendering.
* Attachments are centered on [`PLivingAttachmentDefinition`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachmentDefinition.java), [`PLivingAttachments`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachments.java), [`PAttachmentBinding`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentBinding.java), and [`PAttachmentAnchor`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentAnchor.java).

## Player animations

* [`PPlayerAnimationDefinition`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDefinition.java) configures bindings, masks, blend modes, weights, activation crossfades, cycle synchronization, controllers, Molang queries, and animation-owned mesh deformers through `Builder.deform(...)`.
* [`PPlayerAnimations`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimations.java), [`PPlayerAnimationHandle`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationHandle.java), and [`PPlayerAnimationInstance`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationInstance.java) expose runtime registration and per-player state.
* [`PPlayerPart`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerPart.java), [`PPlayerAnimationMask`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationMask.java), [`PPlayerAnimationBlendMode`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationBlendMode.java), and [`PPlayerAnimationWeight`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationWeight.java) define how a player pose is applied.
* [`PPlayerAnimationDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformer.java), [`PPlayerAnimationDeformerValueSource`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerValueSource.java), and [`PPlayerAnimationDeformerContext`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerContext.java) attach a deformer stack to a definition and sample channels from its player/controller context.

## Mesh deformers

* [`PMeshDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PMeshDeformer.java), [`PDeformerInstance`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PDeformerInstance.java), [`PDeformerStack`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PDeformerStack.java), and [`PChannelReference`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PChannelReference.java) define and evaluate reusable deformations.
* GPU-supported built-in operations are [`PBendDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PBendDeformer.java), [`PHingeDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PHingeDeformer.java), [`PTwistDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PTwistDeformer.java), [`PStretchDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PStretchDeformer.java), [`PSquashDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PSquashDeformer.java), [`PTaperDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PTaperDeformer.java), and [`PWaveDeformer`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PWaveDeformer.java).
* [`PMeshDeformation`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/PMeshDeformation.java) selects optional subdivision and carries runtime values. [`PGpuDeformerBuffers`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/deformer/gpu/PGpuDeformerBuffers.java) uploads supported stacks for queued and instant shaders; [`PDeformedMeshBuffers`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/model/baked/PDeformedMeshBuffers.java) is the fallback cache. [`PPlayerMeshDeformers`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/player/deformer/PPlayerMeshDeformers.java) is the independent player-binding API.

## Events and helpers

* [`PulseLibEvents`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/content/event/PulseLibEvents.java) exposes type, texture, attachment, and player-animation registration events. Use `TypeRegistrationEvent` to add animation-channel, animation-event, or mesh-deformer types; do not register those types directly in NeoForge registries.
* [`PLibHelper`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/helpers/PLibHelper.java), [`PLibCodecs`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/helpers/PLibCodecs.java), and [`PLibDatabase`](https://github.com/ArcAnc/PulseLib/blob/master/src/main/java/com/arcanc/pulselib/util/PLibDatabase.java) are common integration helpers.
